这个系统在做什么

策略不是写出来的，是筛出来的。每个「个体」= 一个完整可运行的交易配置： 策略种类 + 策略参数 + 风控参数（仓位、止损、止盈、熔断阈值）。

  1. 种群初始化：多个策略物种混合竞争同一笔资金。
  2. 适应度 = 训练集 × 0.35 + 验证集 × 0.65 − 泛化落差 × 0.6。 只看回测收益的进化是在做曲线拟合，这里显式惩罚「训练好、验证崩」。
  3. 选择锦标赛 + 精英保留；繁殖交叉 + 变异；重复个体强制再变异。
  4. 测试集全程密封，只在最后给冠军结算一次——这才是可对外报的数字。

引擎已修掉的坑（源自旧仓库审计）

  • 前视偏差：信号在下一根 K 线开盘成交，而非当前收盘。
  • 空头权益算法错误（旧代码用 capital + abs(pos)*close 虚增净值）。
  • 夏普按 t 统计量算 → 改为权益曲线年化夏普 / 索提诺。
  • 风控从未被调用 → 现在每根 K 线调用，熔断会真的平仓并禁止新开仓。
  • RSI 平滑分支写反（avg_l/avg_g）→ 已修正为标准定义。
  • 指标每根 K 线全量重算 O(n²) → 改为流式 O(1)，3000 根回测约 20–50ms。

风险提示

本工具不是投资建议。合成数据上的优异结果不代表真实市场表现。 任何策略上线前都必须先在测试网验证，并设置硬性仓位上限。 加密货币交易可能导致全部本金损失。
